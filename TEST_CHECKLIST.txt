========================================================
  BIZMATCH — FEATURE TEST CHECKLIST
========================================================
Backend: https://zooming-surprise-production.up.railway.app
Test by running: npx expo start --web (or Expo Go)

Legend:  [ ] = not tested   [x] = passed   [!] = failed

--------------------------------------------------------
1. AUTHENTICATION
--------------------------------------------------------

[ ] 1.1 Register — email/password
      - Go to Welcome → Create Account
      - Enter name, email, password
      - Tap "CREATE ACCOUNT"
      - App navigates to Verify OTP screen immediately
      - OTP email arrives in inbox within ~30 seconds

[ ] 1.2 Email OTP verification
      - Enter the 6-digit code from the email
      - App logs in and navigates to main tabs
      - Expected: user is now verified in Railway MySQL
        (users.is_verified = 1)

[ ] 1.3 Resend OTP
      - On Verify OTP screen, tap "Resend"
      - New code arrives in email
      - Old code no longer works

[ ] 1.4 Login — email/password
      - Log out (Profile → Account Settings → Log out)
      - Log back in with email + password
      - Expected: navigates to main tabs

[ ] 1.5 Login — wrong password
      - Enter correct email, wrong password
      - Expected: "Invalid credentials" error shown

[ ] 1.6 Login — unverified account
      - Register a new account but do NOT verify
      - Try to log in
      - Expected: "Email not verified" error

[ ] 1.7 Forgot password
      - On Login screen → "Forgot password?"
      - Enter your email
      - Check inbox for reset link
      - Click link → enter new password
      - Log in with new password

[ ] 1.8 Continue with Google
      - On Welcome or Login screen, tap "Continue with Google"
      - Browser opens Google sign-in
      - Sign in with Google account
      - Returns to app, logged in
      - Expected: user row in MySQL has oauth_provider = 'google'

[ ] 1.9 Google login — existing account
      - Log out
      - Tap "Continue with Google" again with same account
      - Expected: logs in to same account (no duplicate user created)

2. PROFILE
--------------------------------------------------------

[ ] 2.1 Create profile (first time)
      - After registration, go to Profile tab
      - Fill in: bio, skills, role type, venture stage / investment prefs
      - Tap Save
      - Expected: profile saved, no errors

[ ] 2.2 Edit profile
      - Go to Profile → Edit
      - Change bio or a field
      - Save
      - Expected: changes reflected immediately on profile screen

[ ] 2.3 Upload profile photo
      - Go to Edit Profile → tap photo area
      - Select image from library
      - Save
      - Expected: photo appears on profile and in the swipe feed

[ ] 2.4 Change role (entrepreneur ↔ investor)
      - Profile → Account Settings → change role
      - Expected: feed changes to show opposite role

--------------------------------------------------------
3. SWIPE / MATCHING
--------------------------------------------------------
  Setup: you need TWO accounts (different roles) to test matching.
  Account A = entrepreneur, Account B = investor

[ ] 3.1 Feed loads
      - Log in as Account A
      - Go to Discover tab
      - Expected: cards appear (Account B should be visible if profile is filled)

[ ] 3.2 Swipe right (like)
      - Swipe a card to the right (or tap the like button)
      - Expected: card disappears, next card shown

[ ] 3.3 Swipe left (pass)
      - Swipe a card to the left
      - Expected: card disappears

[ ] 3.4 Mutual match
      - Account A likes Account B
      - Log in as Account B, like Account A back
      - Expected: match celebration modal appears

[ ] 3.5 Matches list
      - Go to Matches tab
      - Expected: the matched user appears in the list

[ ] 3.6 Feed recycling
      - Swipe through all cards until feed is empty
      - Expected: previously passed cards reappear

[ ] 3.7 Scoring / feed order
      - Profiles with matching stage + budget + domain
        should appear near the top of the feed

--------------------------------------------------------
4. MESSAGING
--------------------------------------------------------
  Requires an existing match from section 3.

[ ] 4.1 Open chat
      - Go to Matches tab → tap a match
      - Expected: chat screen opens, no 500 error

[ ] 4.2 Send a message
      - Type a message and tap send (▶)
      - Expected: message appears in the bubble on the right

[ ] 4.3 Receive a message
      - From Account B, send a message to Account A
      - On Account A's chat screen (keep it open)
      - Expected: message appears within ~3 seconds (polling)

[ ] 4.4 Date dividers
      - If messages span multiple days
      - Expected: "TODAY" / "YESTERDAY" / date label shown between groups

[ ] 4.5 Empty chat state
      - Open a fresh match with no messages
      - Expected: "Say hello and start the conversation" empty state shown
